# Pulse — live markets dashboard

Live prices for gold, oil, index ETFs and major US stocks, with ranked market news, analyst ratings and an optional Gemini AI brief.

**Open it:** https://mujtabaahmadi548-007.github.io/Pulse_Investing/

Needs a free Finnhub API key (finnhub.io). Optional Gemini key for the AI brief. Keys are stored only in your browser, never in this repo.
